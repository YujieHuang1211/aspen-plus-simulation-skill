## 1. 遇到没做过的工艺：通用上手步骤

下面七步适用于任何工艺。第 3、4 节以后的配方，其实都是按这七步展开的。

1. **判断反应区受什么控制**，这决定用哪个反应器块。
   - 接近化学平衡（高温、催化剂活性高、停留时间足够），如 SMR 出口、高温变换：RGibbs，或者 REquil 写明反应。
   - 平衡有利，但实际产物由催化剂选择性决定，如甲醇合成、FT、MSR、加氢：REquil 并只写催化剂真正促进的反应；或者 RStoic / RYield，给定转化率和选择性。
   - 由淬冷或停留时间决定，如等离子体、裂解、燃烧后急冷：RStoic，转化率由 Cantera 动力学模型给（见 `cross-validation.md`）。
   - 有可靠的动力学参数：RPlug / RCSTR。没有可信参数时不要硬凑。
2. **列组分时想清楚哪些物种允许生成**。这是第 2 节那个陷阱的根源。不允许生成、但在进料里的组分，要么用 REquil 不写进反应（自然成为惰性），要么在 RGibbs 以外的块里处理。
3. **选物性方法**：按 `model-building.md` §2 的表；每个工艺的推荐写在下面各节。
4. **先用 Cantera 算一个平衡锚点**：`scripts/equilibrium_check.py`，限定物种、标出惰性组分。它给出 Aspen 结果应该落在哪个量级。
5. **在 Aspen 里搭最小模型**，先只放反应器和一个分离，跑通、和锚点对上，再加换热网络、循环和公用工程。一上来搭全流程，出了问题分不清是哪一块。
6. **用 `run()['trusted']` 把关**：组分没从数据库查到、物性参数缺失、块报错，都会让它变成 False。
7. **做 `model-building.md` §6 的五项自查**，再按 `cross-validation.md` 判断要不要叫搭档。

没把握的块参数，先用 `aspen_com.py` 的 `options(路径)` 读出合法取值，用 `tree` 看节点名，不要凭记忆猜关键字。本技能写作过程中，凭记忆写的关键字有三个是错的（RGibbs 的 `IDENTIFY`、组分名 `CH3OH`、压缩机漏了 `OPT_SPEC`），都是这两个办法查出来的。

## 2. 最大的陷阱：平衡计算全部变成甲烷

在 C/H/O 体系里，几百 ℃ 下热力学最稳定的往往是 CH₄ + CO₂ + H₂O。平衡求解器（Aspen RGibbs、Cantera、CEA）只要允许 CH₄ 生成，低温催化工艺的结果就会全部被甲烷化吞掉。实测：

| 工况（理想气体平衡，允许 CH₄ 生成） | 结果 | 实际催化剂的结果 |
|---|---|---|
| 甲醇合成，250 ℃、80 bar，H₂/CO/CO₂/CH₄ = 70/20/7/3 | 甲醇 0（Aspen RGibbs 2×10⁻¹⁰），CH₄ 46% | 铜基催化剂不催化甲烷化，出口甲醇为主 |
| 甲醇水蒸气重整，250 ℃、1.5 bar，水醇比 1.5 | 干基 CH₄ 71%，H₂ 只有 4% | 干基 H₂ 约 75% |
| 变换，350 ℃、30 bar，SMR 出口气 | 干基 CH₄ 86% | CH₄ 不变，CO 降到 1%～2% |
| FT，220 ℃、25 bar，H₂/CO = 2 | 只剩 CH₄、CO₂、H₂O | 长链烃，ASF 分布 |

规则：

- 催化剂不促进的反应，不要让平衡块替它发生。用 REquil 只写目标反应（实测可行，见第 4、5 节），或者组分表里干脆不放不该生成的物种。
- RGibbs 理论上可以设 `PROD_SPEC = PRODUCTS` 并列出允许的产物。但本机 V11 上通过 COM 填产物表一直报 `AE_UNDERSPEC`，没有成功（试过三种写法，导出的 .inp 里都没有产物列表）。需要限定产物时，用 REquil；确实要用 RGibbs 产物表，在 GUI 里填。
- SMR、ATR、POX 这类高温工艺，甲烷本来就是反应物之一，允许 CH₄ 参与平衡是对的。

## 3. 天然气重整（SMR / ATR / POX）与水煤气变换

**组分**：CH₄、C₂H₆（视原料）、H₂O、H₂、CO、CO₂、N₂、Ar；ATR/POX 加 O₂。

**物性方法**：PENG-ROB 或 RK-SOAVE（实测 SMR 用 PENG-ROB）。下游冷凝分离水时，水相用同一 EOS 足够做热平衡；要算溶解气和废水，换 NRTL + Henry。

**反应器**：
- 转化炉：RGibbs，给出口温度和压力。实测 850 ℃、30 bar、S/C = 3：Aspen CH₄ 转化率 76.3%，Cantera 理想气体 76.7%；干基 H₂ 72.2%、CO 12.6%、CO₂ 8.6%、CH₄ 6.6%。
- 工业转化炉出口通常离平衡差十几到几十度（典型值）。RGibbs 有 `TAPP`（趋近平衡温差）输入可以表达这一点（**未实测**）；或者把 RGibbs 温度设低一些，在报告里写明这是平衡趋近假设。
- 变换（HTS / LTS）：REquil，只写 CO + H₂O = CO₂ + H₂，CH₄ 作为惰性随流。实测 350 ℃、30 bar（SMR 出口气加水）：Aspen 干基 CO 1.45%，Cantera 1.42%；Cantera 扫描 200 / 300 / 400 ℃：CO 0.14% / 0.78% / 2.30%。
- ATR / POX：RGibbs 绝热（给热负荷 0）或给出口温度，O₂ 进料由氧碳比定（**未实测**）。出口温度高（典型 950～1050 ℃），检查有没有积碳：RGibbs 组分表里加 C（固体，需 SOLIDS 子流股，**未实测**），或用 Cantera 算 Boudouard 平衡。

**陷阱**：
- 变换反应器用 RGibbs 不限定产物，CO 会被甲烷化吞掉（第 2 节）。
- 转化炉的热量：RGibbs 负荷只是工艺侧吸热，燃烧侧（燃料、空气、烟气、炉效率）要另建燃烧模型，或按炉效率假设折算。
- 高 S/C 下大量水蒸气，换热网络的露点和冷凝段要单独核对。

**锚点命令**：
```bash
python scripts/equilibrium_check.py --T 850 --P 30 --feed CH4:1,H2O:3 --species CH4,H2O,H2,CO,CO2
python scripts/equilibrium_check.py --T 350 --P 30 --feed <SMR出口> --species H2O,H2,CO,CO2 --inert CH4 --sweep-T 200,400,50
```

## 4. 甲醇水蒸气重整（MSR）

**组分**：CH₃OH（Aspen 数据库名 `METHANOL`，不是 `CH3OH`）、H₂O、H₂、CO、CO₂。进料是液体时，汽化器单独建块。

**物性方法**：液相甲醇–水用 NRTL（汽化、冷凝、未反应醇水回收）；反应器气相用 PENG-ROB 或理想气体。同一流程里用两种方法时，在块上单独指定 property method。

**反应器**：REquil 写两个反应：CH₃OH + H₂O → CO₂ + 3H₂；CO₂ + H₂ → CO + H₂O（逆变换决定 CO 含量）。实测 250 ℃、1.5 bar、水醇比 1.5：Aspen 干基 H₂ 74.65%、CO 1.40%、CO₂ 23.95%，Cantera 74.65 / 1.41 / 23.94，甲醇几乎全转化。

**陷阱**：
- 平衡 CO 含量就是上面的 1.4%（250 ℃）；实际出口 CO 由催化剂动力学决定，可能低于平衡值。给燃料电池（PEMFC 对 CO 敏感）供氢时，CO 要用催化剂厂家数据或试验值，不能只报平衡值。
- RGibbs 不限定产物会算出 71% 甲烷（第 2 节）。
- 吸热反应，供热方式（导热油、燃烧尾气）决定能效，热负荷取反应器块负荷加汽化负荷。

## 5. 甲醇合成

**组分**：H₂、CO、CO₂、CH₃OH（`METHANOL`）、H₂O、CH₄、N₂（惰性）；精馏段要算副产物时再加二甲醚、高级醇（**未实测**）。

**物性方法**：合成回路 PENG-ROB 或 RK-SOAVE（实测 PENG-ROB）；高压下甲醇–水冷凝分离，极性强，SR-POLAR 或 PSRK 更稳妥（**未实测**）；粗甲醇精馏用 NRTL。

**反应器**：
- 热平衡和回路物料：REquil，两个反应 CO + 2H₂ = CH₃OH，CO₂ + H₂ = CO + H₂O，CH₄、N₂ 不写进反应即成惰性。实测 250 ℃、80 bar、H₂/CO/CO₂/CH₄ = 70/20/7/3：出口甲醇 26.9 mol%（PENG-ROB），Cantera 理想气体 24.2%。高压下非理想性让平衡更有利，差值方向合理。
- 实际反应器离平衡有距离，单程转化率由动力学决定。有可信的动力学（文献上常用 LHHW 型）时用 RPlug（**未实测**）；没有时，用 REquil 加趋近平衡温差，或 RStoic 给单程转化率，并标为工程假设。

**陷阱**：
- 甲烷化陷阱（第 2 节）。
- 回路有大循环、弛放气，惰性组分（CH₄、N₂）会累积。撕裂流初值、弛放比要合理，见 `model-building.md` §4。
- 合成气模数 M = (H₂ − CO₂)/(CO + CO₂) 是判断配比的常用指标，理想约为 2（典型值），写进基准表。

## 6. 费托合成（FT）

**组分**：H₂、CO、CO₂、H₂O、CH₄，C₂～C₄ 轻烃，再用一组正构烷烃或假组分代表石脑油、柴油、蜡（如 C₅～C₁₀、C₁₁～C₂₀、C₂₁+）。

**物性方法**：气相回路 PENG-ROB；三相分离（水 / 油 / 气）要能算液液分相，PENG-ROB 配合 free-water 选项，或 SRK（**未实测**）；蜡用假组分时注意沸点和临界参数来源。

**反应器**：平衡块不能用（第 2 节：平衡下只剩 CH₄、CO₂、H₂O）。用：
- RYield：产物分布按 ASF（Anderson–Schulz–Flory）给定。碳数 n 的质量分数 Wₙ = n(1−α)²αⁿ⁻¹，α 是链增长概率（典型值：钴基低温 FT 约 0.85～0.92，铁基高温 FT 更低）；甲烷和 C₂ 实际偏离 ASF，常单独给定。
- 或 RStoic：每个产物写一个反应，CO 转化率和选择性来自试验或文献。

**陷阱**：
- RYield 按质量归一，不自动保证元素守恒，C、H、O 进出要自己核对（`model-building.md` §6）。
- 收率是固定输入，工况变了不会跟着变；做敏感性分析时，α 和 CO 转化率要作为输入一起扫。
- 强放热，反应器撤热（列管水汽化、浆态床内冷管）是设备选型的主要依据，热负荷取 RYield / RStoic 块负荷。
- 尾气循环比、CO₂ 累积、水分压对催化剂的影响，Aspen 不会提示，要在假设清单里写明。

本节的建模方法本机**未实测**。第一次用时，先拿一组文献数据（给定 α、转化率）复现产物分布和热负荷。

## 7. PSA 变压吸附

Aspen Plus 没有动态吸附床模型。周期、床层、均压步骤要用 Aspen Adsorption（单独的产品，本机未确认是否安装）或厂家软件。流程模拟里 PSA 用 **Sep 块**表示：给每个组分进产品气的分率。

**实测**：Sep 块，进料 H₂/CO/CO₂/CH₄ = 0.75/0.03/0.18/0.04 kmol/h、20 bar；H₂ 进产品的分率 0.85、其余 0 → 产品 H₂ 0.6375 kmol/h（= 0.75 × 0.85），纯度 100%。节点：`\Data\Blocks\<B>\Input\FRACS\<产品物流>\MIXED\<组分>`。

**怎么给分率**：
- H₂ 回收率和产品纯度是厂家的性能参数。氢气 PSA 的回收率典型 75%～90%，纯度 99.9%～99.999%（典型值），与原料组成、压力、塔数有关。
- 杂质不要全给 0：按厂家的产品纯度反推杂质进产品的分率，否则纯度永远 100%，下游对杂质敏感的设备（燃料电池、加氢催化剂）会被误判。
- 尾气压力（通常接近常压）和尾气去向（作燃料返回转化炉）决定全厂热平衡，在 Sep 后接一个降压阀或 HEATER 设定压力。

**陷阱**：Sep 块不算能耗，压缩功、程控阀和吸附剂寿命都不在模型里。

## 8. 精馏

**物性方法**：醇–水、酸–水等极性体系用 NRTL / UNIQUAC，先 Retrieve Parameters 看二元参数（实测甲醇–水 NRTL 参数齐全）；烃类用 PENG-ROB / RK-SOAVE；有共沸物时先查 Aspen 的共沸分析或文献，确认分离路线可行。

**先估算，再严格计算**：DSTWU（Fenske–Underwood–Gilliland 简捷法）给最小回流比、最少理论板数，拿它的结果作为 RadFrac 的初值（**DSTWU 未实测**）。

**RadFrac（实测）**：甲醇–水 1 kmol/h 等摩尔、25 ℃、1 atm，15 块理论板、第 8 块进料、全凝器、回流比 1.5、馏出比 D/F = 0.5（摩尔）→ 塔顶甲醇 99.1%，塔底水 99.1%，再沸器 13.8 kW，冷凝器 −12.3 kW。手算校核：上升蒸汽 (1 + 1.5) × 0.5 = 1.25 kmol/h，乘以汽化潜热约 35～40 MJ/kmol，得 12～14 kW，吻合。

常用节点（实测）：

| 量 | 路径 |
|---|---|
| 理论板数 | `...\Input\NSTAGE` |
| 冷凝器类型 | `...\Input\CONDENSER`（`NONE` / `TOTAL` / `PARTIAL-V` / `PARTIAL-V-L`） |
| 进料板 | `...\Input\FEED_STAGE\<进料物流>` |
| 塔顶压力 | `...\Input\PRES1` |
| 回流比 / 馏出比 | `...\Input\BASIS_RR`、`...\Input\D:F`（基准 `RR_BASIS`、`D:F_BASIS`：`MOLE` / `MASS` / `STDVOL`） |
| 冷凝器 / 再沸器负荷 | `...\Output\COND_DUTY`、`...\Output\REB_DUTY`（MET 下单位 cal/sec） |

出口端口：`LD(OUT)` 液相馏出、`VD(OUT)` 气相馏出、`B(OUT)` 塔釜、`SP(OUT)` 侧线。

**陷阱**：
- 规定纯度时用 Design Spec 调回流比或馏出量，不要手工试凑。纯度规定离可达范围太近会不收敛，先用敏感性扫描确认可达。
- 理论板数到实际塔板要除以板效率，填料塔要用 HETP；水力计算（塔径、液泛）在 RadFrac 的 Tray / Pack Rating 里做，或交给专门软件，结果是设备选型的主要依据。

## 9. 加氢装置

分两类，建法不同：

- **纯物质加氢**（如芳烃加氢、不饱和醛酮加氢、CO₂ 加氢）：组分明确，PENG-ROB 或 RK-SOAVE；反应器用 RStoic（给转化率和选择性）或 REquil（平衡限制明显时），放热量取块负荷。
- **石油馏分加氢精制 / 加氢裂化**：原料用 Assay 和假组分表示，物性方法常用 BK10、Grayson-Streed 或 PENG-ROB（石油体系的常见选择，具体以 Aspen 帮助和项目数据为准）；反应用 RYield 或 RStoic（给脱硫率、脱氮率、裂化收率），H₂S、NH₃ 作为产物。

两类共同的要点（**未实测**，第一次用时验证）：
- 氢气消耗分化学耗氢、溶解损失和尾氢排放三部分。高压分离器的 H₂ 溶解量对物性方法敏感（EOS 的 H₂–烃二元参数），要和文献或厂家数据比。
- 氢油比、循环氢压缩机、急冷氢的流量由反应器温升决定。强放热时分段进料或段间急冷，用多个 RStoic 串联，每段给温升上限。
- 高压分离器、低压分离器和循环氢脱硫（胺洗，ELECNRTL）是独立的子系统，分开建、分开验。

## 10. 常用单元：压缩、换热、闪蒸

**压缩机 COMPR（实测）**：H₂ 1 kmol/h、40 ℃，1 → 3 bar，等熵效率 0.75 → 出口 193.8 ℃，轴功约 1.25 kW（手算 n·cp·ΔT = 1/3600 × 29.1 × 153.8 ≈ 1.24 kW）。

| 量 | 路径 / 取值 |
|---|---|
| 模型 | `...\Input\TYPE`：`ISENTROPIC`、`GPSA-POLYTROP`、`ASME-POLYTROP`、`POS-DISP` 等 |
| 指定方式 | `...\Input\OPT_SPEC`：`PRES` / `DELP` / `PRATIO` / `POWER` / `USE-CURVE`。**必须先设它**，只填 `PRES` 会报 "NO PRESSURE OR WORK SPECIFICATIONS ARE GIVEN" |
| 出口压力、等熵效率 | `...\Input\PRES`、`...\Input\SEFF` |
| 轴功 | `...\Output\WNET`，**MET 下单位是 kW**，不是热负荷用的 cal/sec。同一单位集里不同的量单位不同，读数前用 `unit()` 看 |

多级压缩加级间冷却用 MCOMPR，或多个 COMPR + HEATER 串联（**未实测**）。

**换热**：只要负荷用 HEATER；要两股物流换热、看温差交叉用 HEATX（P47 实测）；详细几何和压降交给 HTRI（`cross-validation.md`）。

**闪蒸**：FLASH2（气液）、FLASH3（气液液，FT 产物、烃–水分离时用，**未实测**）。
